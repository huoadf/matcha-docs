Give any MCP-capable agent live search & read access to these docs.

MCP server URL
https://huoadf.github.io/matcha-docs/mcp

Run in your terminal:

claude mcp add --transport http matcha-docs https://huoadf.github.io/matcha-docs/mcp

Add to .cursor/mcp.json:

{
  "mcpServers": {
    "matcha-docs": {
      "url": "https://huoadf.github.io/matcha-docs/mcp"
    }
